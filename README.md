# PureFlow_project

Editor de mundos hecho con HTML, CSS y JavaScript, usando Bootstrap (vía npm) y Vite como servidor de desarrollo.

## Requisitos

- Node.js y npm instalados. Revisá con:
  ```
  node -v
  npm -v
  ```
  Si no los tenés, bajalos de [nodejs.org](https://nodejs.org) (versión LTS).

## Cómo levantar el proyecto

```
npm install
npm run dev
```

Esto instala las dependencias (Bootstrap, Vite, Sass) y abre el proyecto en el navegador con recarga automática.

## Build para producción

```
npm run build
```

Genera la carpeta `dist/` con HTML, CSS y JS listos para publicar, sin necesidad de Node para abrirlos.
